# EduPLAN - The Ultimate Student Assignment Planner

EduPLAN is a modern, feature-rich Android application designed to help students manage their assignments, projects, and deadlines effectively.

## Key Features

* **Smart Notification System:** Customizable reminders tailored to assignment difficulty (Easy, Normal, Hard) and specific project deadlines.
* **Pro Mode (Voice to Text):** Real-time voice recording with automatic `.md` file transcription for quick lecture notes.
* **QR Code Sharing:** Instantly share your entire assignment schedule with classmates or import new tasks via QR code.
* **Bilingual Support:** Fully functional in both English and Turkish.
* **Customizable UI:** Clean interface with seamless switching between Light and Dark themes.
